# Hi, I'm Radmir 👋

I'm a former industrial automation engineer now focused on building practical AI systems, automation, and local AI infrastructure.

## 🔥 What I'm building

My main project is **ISKRA CORE** — a local-first, persistent AI system designed to become a reliable AI operating layer rather than just another chatbot.

The long-term idea is to combine:

- persistent memory and state
- local LLMs
- controlled tools and workflows
- automation
- recovery and versioning
- secure permissions
- business-oriented AI workflows
- replaceable models and components

The project is being developed incrementally, with reliability, real-world usefulness, security, and economic value taking priority over flashy demos.

Most of ISKRA CORE is currently kept private while the architecture is still actively evolving.

## 🎯 Why I'm doing this

I believe useful AI should do more than answer questions.

I want to build systems that can retain knowledge, use tools safely, automate real work, learn from measured results, and reduce the amount of repetitive human effort required.

ISKRA CORE is my attempt to explore that direction through a real working system rather than only theory or demos.
